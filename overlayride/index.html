Cara membuat API app Strava (sekali saja)

1. Buka strava.com/settings/api sambil login akun Strava-mu.
2. Application Name: bebas, mis. OverlayRide. Category: Other.
3. Website: bebas, mis. https://www.strava.com.
4. Authorization Callback Domain: isi persis seperti kotak di atas.
5. Klik Create → salin Client ID dan Client Secret ke formulir di atas.
